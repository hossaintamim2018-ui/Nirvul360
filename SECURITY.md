# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Nirvul360, please do not disclose it publicly via GitHub issues.
Instead, please email security concerns directly to the project maintainers with:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact and affected components

Maintainers will review the report and coordinate a patch promptly.
